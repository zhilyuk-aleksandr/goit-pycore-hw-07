# Домашня робота 07 · Тема 10

Консольний бот веде адресну книгу протягом одного сеансу. Для запуску з теки роботи потрібен Python 3 зі стандартною бібліотекою.

```bash
python3 main.py
```

Приклад команд для одного контакту

```text
hello
add Olena 0501234567
add Olena 0670000000
change Olena 0670000000 0671111111
phone Olena
add-birthday Olena 29.02.2000
show-birthday Olena
all
birthdays
exit
```

`phone Olena` виведе `0501234567; 0671111111`, а `show-birthday Olena` — `29.02.2000`. Команди `exit` і `close` завершують сеанс.

Ім’я вводьте одним словом, номер — десятьма цифрами, дату — у форматі `ДД.ММ.РРРР`. Команда `birthdays` враховує сьогодні та шість наступних днів. Привітання із суботи й неділі переноситься на понеділок, навіть якщо він за межами цього періоду. У невисокосний рік для 29 лютого береться 28 лютого.
